## 1. Modern Yose — 詳細仕様

### ターゲット
- 定期的に寄席・落語会を主催している団体・個人
- 写真素材は最小限でも成立させたい
- スマートフォンからの予約が主流

### カラーパレット

| 変数名 | HEX | 用途 |
|--------|-----|------|
| `--color-bg` | `#0f0f0f` | 背景（漆黒） |
| `--color-surface` | `#1a1a1a` | カードやセクション背景 |
| `--color-border` | `#2e2e2e` | 区切り線 |
| `--color-accent` | `#c0392b` | 朱色・CTAボタン・バッジ |
| `--color-accent-light` | `#e74c3c` | ホバー |
| `--color-text` | `#f0ebe3` | 本文（温かみのあるオフホワイト） |
| `--color-text-muted` | `#8a8278` | 補足テキスト |
| `--color-gold` | `#c9a96e` | アクセント（演者名・日付） |

### タイポグラフィ

- 見出し: `Noto Serif JP` (Google Fonts)
- 本文: `Noto Sans JP`
- 英数字補助: `Cormorant Garamond` or `EB Garamond`
- 基準サイズ: 16px / 行間 1.8

### セクション構成（上から順）

#### 0. ナビゲーションバー（固定）
- ロゴ/公演名（左）
- 予約ボタン（右）
- スクロール時に背景が半透明になる

#### 1. ヒーローセクション
**必須要素**
- 公演名（大見出し）
- キャッチコピー（サブタイトル）
- 日付・開演時間・開場時間
- 会場名
- 予約ボタン（朱色）
- 残席バッジ（5パターン用意）

**バッジパターン**
```
[発売前] 朱枠・白文字
[予約受付中] 緑色
[残席わずか] オレンジ
[満席] グレーアウト
[当日券あり] 水色
```

**背景オプション（コメントで切替）**
- Option A: 和紙テクスチャ風グラデーション（画像なし）
- Option B: 写真画像背景（オーバーレイ付き）

#### 2. 番組表セクション
- 出演順リスト
- 演目名（任意）
- 出演者名
- 前座 / 二つ目 / 真打 のバッジ
- 仲入り（休憩）行

#### 3. 出演者セクション
- グリッドカード（2列/スマホ1列）
- 写真（あり/なし両対応）
- 師匠名・出身・一言紹介
- SNSアイコン（任意）

#### 4. 料金セクション
- 木戸銭テーブル（前売/当日/学生/特別席）
- 注意事項
- 予約ボタン（複数サービス対応）

**対応予約サービスボタン**
- Peatix
- TIGET
- PassMarket
- Googleフォーム
- メール予約

#### 5. 会場・アクセスセクション
- 会場名・住所・電話番号
- Google Mapsインライン埋め込み（iframeプレースホルダー）
- 最寄り駅・徒歩時間
- バリアフリー情報（任意）

#### 6. FAQセクション
アコーディオン形式、デフォルト設問：
1. 開場・開演時間はいつですか？
2. 途中入場はできますか？
3. 未就学児・乳幼児は入場できますか？
4. 写真・動画撮影はできますか？
5. キャンセル・払い戻しはできますか？
6. 当日券はありますか？
7. 座席指定はありますか？
8. 駐車場はありますか？

#### 7. フッター
- 主催者名・連絡先
- SNSリンク
- 過去公演リンク（任意）
- プライバシーポリシー

#### 8. スマホ固定CTAバー
- 画面下部に常時表示
- 「予約する →」ボタン
- 日付・残席情報を1行で表示

### 技術仕様

- **単ファイル構成**: `index.html` 1本（CSS・JSをインライン埋め込み）
- **外部依存**: Google Fonts のみ（CDN）
- **JavaScript**: バニラJS（フレームワーク不使用）
- **アクセシビリティ**: `lang="ja"`, `alt` 属性, `aria-label`, キーボード操作対応FAQ
- **OGP/SNSシェア**: `og:title`, `og:description`, `og:image` プレースホルダー
- **印刷CSS**: `@media print` で不要要素を非表示
